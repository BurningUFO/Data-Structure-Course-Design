##景区内部参数

## 一、顶层参数

| 参数           | 类型     | 必填  | 说明                                |
| ------------ | ------ | --- | --------------------------------- |
| `graph_id`   | string | ✅   | 当前图层唯一ID，供其他图层的门引用                |
| `graph_type` | string | ✅   | 图层类型：`outdoor`/`indoor`/`parking` |

## 二、节点参数

| 参数                | 类型          | 必填  | 说明                                          |
| ----------------- | ----------- | --- | ------------------------------------------- |
| `node_id`         | string      | ✅   | 节点唯一ID（图层内唯一）                               |
| `name`            | string      | ✅   | 显示名称（如"北门"）                                 |
| `is_gate`         | boolean     | ✅   | `true`=门节点（触发图层切换），`false`=普通节点             |
| `sub_graph_id`    | string/null | ✅   | 门通向的图层ID；普通节点填`null`                        |
| `connected_nodes` | array       | ✅   | 连接关系，格式：`[{"target":"节点ID","distance":米数}]` |





# 旅游日记 JSON 参数标准（精简版）

## 一、顶层参数

| 参数            | 类型     | 必填  | 说明     |
| ------------- | ------ | --- | ------ |
| `id`          | string | ✅   | 日记唯一ID |
| `title`       | string | ✅   | 日记标题   |
| `destination` | string | ✅   | 目的地名称  |
| `author_id`   | string | ✅   | 作者用户ID |

## 二、内容参数

| 参数           | 类型     | 必填  | 说明                      |
| ------------ | ------ | --- | ----------------------- |
| `content`    | string | ✅   | 日记正文                    |
| `heat`       | int    | ✅   | 热度值（阅读/互动量）             |
| `rating`     | float  | ✅   | 评分（1.0-5.0）             |
| `tags`       | array  | ✅   | 标签列表，格式：`["标签1","标签2"]` |
| `created_at` | string | ✅   | 创建日期，格式：`YYYY-MM-DD`    |



## 景区参数说明

| 参数            | 类型     | 必填  | 说明                         |
| ------------- | ------ | --- | -------------------------- |
| `id`          | string | ✅   | 唯一标识                       |
| `name`        | string | ✅   | 名称                         |
| `category`    | string | ✅   | 类别                         |
| `heat`        | number | ✅   | 热度值                        |
| `rating`      | number | ✅   | 评分                         |
| `tags`        | array  | ✅   | 标签列表，格式：`["标签1","标签2"]`    |
| `keywords`    | array  | ✅   | 关键字列表，格式：`["关键词1","关键词2"]` |
| `description` | string | ✅   | 描述信息                       |
