----------------
  表现层 (UI/CLI)            — Flask Web + Leaflet 地图
      |
  业务层 (查询/推荐/日记)    — 模糊搜索、Top-K、兴趣推荐
      |
  算法层 (图/路径)           — Dijkstra、状态压缩 DP
      |
  数据层 (JSON/压缩/检索)    — 景区注册表、哈夫曼、倒排索引

数据流向：
  Member C(数据层) → Member A(建图)

  Member A(距离接口) → Member B(排序)
  Member C(全文检索) → Member B(日记展示)


四、核心数据结构
----------------

1. 图结构 (Graph)
   - 邻接表: adj = {node_id: [{to, distance, ...}, ...]}
   - 节点属性: nodes = {node_id: {name, type, ...}}
   - 多层嵌套: sub_graphs = {parent_node_id: Graph}
   - 递归查找: find_node_recursive()

2. 小顶堆 (MinHeap) → Top-K
   - 自定义 _shift_up / _shift_down 堆化
   - 降序Top-K用原值入堆，堆顶=第K大最小值
   - O(n log k)

3. 归并排序 (Merge Sort)
   - 多字段动态排序规则
   - 稳定排序
   - O(n log n) / O(n)

4. 哈夫曼树 (Huffman)
   - 频率统计 → 建堆 → 两两合并 → 编码表(左0右1)
   - 编码 → pack_bits → 字节流
   - 带压缩比估算

5. 倒排索引 (Inverted Index)
   - CJK n-gram分词(2~8字窗口)
   - 字段加权: title×18, tags×14, dest×10, content×6
   - 同义词展开


五、核心算法
------------

1. Dijkstra 最短路径
   - heapq优先级队列 + 提前终止
   - 交通方式过滤(walk/bike/mixed)
   - 距离策略 / 时间策略(speed×congestion)

2. 多目标路径 (Held-Karp 状态压缩DP)
   - DP[mask][last] = 访问mask目标集、目前在last的最小代价
   - O(n²·2ⁿ)，限制n≤12

3. 模糊查询评分
   精确160/前缀120/包含90/跳字缩写72/编辑距离64
   同义词组：洗手间↔wc↔restroom
   编辑距离：3字内1次编辑，4-8字2次

4. 兴趣推荐
   兴趣匹配0.45 + 热度0.25 + 评分0.20 + 距离0.10


六、模板克隆机制
----------------
180+ 景区只复用 PKU 一份物理数据。
  {"id": "BNU", "template_site_id": "PKU",
   "display_overrides": {
     "node_names": {"gate_north": "北师大西门"},
     "text_replacements": {"北京大学": "北京师范大学"}}}

解析流程：
  BNU → resolve_site_data_id() → PKU → 加载PKU图 → 应用改名 → 展示
