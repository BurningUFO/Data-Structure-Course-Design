# 用户使用说明

> 文档状态：第13周正式产品冻结版，配合 `工作进度/第十三周/第十三周具体工作任务要求.md` 和冻结周回归记录使用。

---

## 1. 系统简介

本系统面向景区 / 校园游览场景，提供旅游推荐、路线规划、场所查询、美食推荐、旅游日记管理与交流等功能。第13周正式验收以 Web UI 为主入口，CLI 仅作为兜底调试方式。当前地图演示采用 Leaflet + GeoJSON 实验层，并保留 SVG 简图作为稳定回退。

---

## 2. 启动方式

### 2.1 环境要求

- Windows + Python 3
- 项目代码位于仓库根目录
- 本仓库当前推荐使用 `py` / `py -3` 启动；若 `python` 命中 WindowsApps 占位程序，请不要把它作为有效解释器。

### 2.2 启动步骤

1. 打开项目根目录终端。
2. 运行：

```powershell
py -B -m src.ui.demo_server
```

如需显式指定 Python 3，可使用：

```powershell
py -3 -B -m src.ui.demo_server
```

3. 在浏览器访问：

```text
http://127.0.0.1:8765
```

如果当前环境没有 `py` 启动器，可使用同一 Python 环境运行：

```powershell
python -B -m src.ui.demo_server
```

## 3. 主要页面说明

### 3.1 首页 / 站点选择

- 查看当前可用站点、系统统计信息和预设演示入口。
- 切换站点后，当前查询条件和路径高亮会自动重置。
- 当前课程口径为“1 个深度导航核心站点 PKU + 200+ 扩展推荐 / 查询对象池”，不承诺所有扩展对象都能直接深度导航。

### 3.2 综合查询与推荐

- 输入景点 / 学校名称、类别或关键字进行查询。
- 可选择“当前用户”或直接编辑“当前兴趣偏好”，按兴趣、热度、评分和距离综合查看推荐结果。

### 3.3 导航规划

- 输入起点和目标点，可查看最短距离或最短时间路线。
- 交通方式提供“步行”“自行车”“步行 + 自行车最短时间”。其中混合交通会在室外按总时间选择步行或自行车边，入楼后仍使用步行语义。
- 多目标模式支持依次访问多个地点并返回起点。
- 第13周冻结字段包括访问顺序、分段结果、路径步骤、层级序列、总距离和预计时间；页面展示不得依赖临时调试字段。
- 地图区默认使用 Leaflet GeoJSON 实验层展示节点、道路和路线高亮。
- 点击地图区的 `SVG` / `Leaflet` 可切换稳定简图和真实地图实验层。
- 路线摘要会说明当前路线中真实 geometry 段数和 fallback 直线段数。
- 点击支持室内导航的建筑后，可进入室内平面图；室内图以房间面、走廊通行带、墙体、门洞和设施图标展示，并支持楼层切换。
- 当路线包含室内段时，可在室内 / 室外路线视图之间切换，室内路线高亮会叠加在走廊和目标功能区之上。

### 3.4 场所与美食

- 查询附近设施，支持按类别过滤。
- 查看按热度、评分和真实路径距离排序的美食推荐结果。

### 3.5 日记中心

- 支持日记创建、编辑、删除、评分和浏览量展示。
- 支持“浏览 / 推荐日记”和“全文检索”两种入口；推荐模式会结合当前用户兴趣、日记热度和评分排序。
- 支持按目的地、标题和正文关键字检索日记。
- 可查看压缩 / 解压摘要与 AIGC 动画预览入口。

### 3.6 帮助与演示

- 使用固定预设参数快速跑通验收链路。
- 查看错误提示说明、输入约束和演示建议步骤。

## 4. 推荐操作流程

### 4.1 景点推荐

1. 进入“综合查询与推荐”。
2. 在顶部选择“当前用户”，或在“当前兴趣偏好”中输入兴趣标签。
3. 选择站点、输入关键字或直接使用“按兴趣综合”排序。
4. 查看 Top-K 推荐结果和“兴趣命中”解释，再从结果定位或规划路线。

### 4.2 路线规划

1. 进入“导航规划”。
2. 选择起点、目标点和路线策略。
3. 点击查询，查看路径高亮、步骤说明和距离 / 时间摘要。
4. 第13周固定路线演示：
   - `gate_north -> library`：单目标最短距离路线，展示地图贴路高亮和步骤说明。
   - `gate_north -> library -> canteen`：多目标路线，展示访问顺序、分段摘要和总距离 / 总时间。
   - `library -> lib_reading_room_1`：纯室内路线，展示楼层 / 室内路径高亮。
   - `gate_north -> lib_reading_room_1`：跨层路线，展示室外到室内的自动衔接。
5. M21 交通方式固定演示：
   - `gate_east -> parking_lot`：最短时间下步行优于自行车绕行。
   - `gate_south -> sports_ground`：自行车明显快于纯步行，混合交通因可先步行接驳再骑行而最快。
   - `gate_south -> lib_reading_room_1`：室外可用混合交通，进入图书馆后 `gate_link` 和室内段仍按步行展示。
   - `library -> lib_reading_room_1`：纯室内路线保持步行语义。

### 4.3 地图方案 B 演示

1. 进入“主要网站”，确认右侧地图区默认显示 Leaflet GeoJSON 实验层。
2. 点击地图区 `SVG`，确认旧版稳定简图可用；再点击 `Leaflet` 切回实验层。
3. 点击 `演示单目标`，展示 `gate_north -> library` 的贴路高亮。
4. 点击 `演示多目标`，展示从 `gate_north` 访问 `library` 和 `canteen` 的多段路线。
5. 在综合查询中搜索“图书馆”，点击“地图定位”或“从当前起点规划路线”，确认查询结果可联动地图。
6. 说明 `fallback 直线段`：道路 edge 暂无手工 geometry 时，系统用 from/to 节点坐标生成直线段，保证地图和路线规划不崩溃。

### 4.4 室内平面导览演示

1. 在导航规划页点击图书馆、第一教学楼、学生宿舍31楼或食堂类建筑的“进入室内导航”。
2. 确认室内图能看到入口大厅、走廊、房间 / 功能区、洗手间、电梯、楼梯间、墙体和门洞。
3. 使用楼层切换按钮查看不同楼层。
4. 选择一个室内功能区并点击“规划路线”，确认路线高亮沿走廊通行带叠加，并最终指向目标区域。

### 4.5 日记检索与 AIGC 预览

1. 进入“日记中心”。
2. 点击“浏览推荐日记”，查看按当前兴趣偏好、热度和评分综合排序的全部日记。
3. 输入正文关键字可切换到全文检索入口，查看命中日记、匹配词和评分信息。
4. 日记结果仍可进入编辑、评分、删除和路线规划。
5. 如需演示 AIGC，上传或选择样例图片并输入文字描述，查看预览结果。

### 4.6 M23 固定兴趣推荐演示

1. 选择用户 `张三(user_001)`，兴趣为“校园、秋景、图书馆”，综合查询推荐首位应偏向图书馆 / 校园学习类结果，日记推荐首屏偏向“秋日燕园游记”或“图书馆自习攻略”。
2. 切换用户 `李四(user_002)`，兴趣为“美食、食堂、校园生活”，综合查询推荐首位应偏向“农园食堂”，日记推荐首位应为“农园食堂美食测评”。
3. 两组结果卡片会展示兴趣分、综合分和兴趣命中来源。

## 5. 注意事项

- 如果切换站点后结果异常，请重新执行查询，避免沿用旧状态。
- 路线不可达时，系统会给出失败提示，不会强行返回伪路径。
- Leaflet 或 GeoJSON 加载失败时，前端会自动切换到 `simple_svg` 稳定简图。
- fallback 直线段不是路径算法失败，只表示该道路边还没有完整 geometry。
- AIGC 动画生成功能当前为轻量演示版本，重点展示输入输出闭环，不代表最终商用级生成质量。
- 日记新增 / 编辑当前为内存态演示，不写回标准样例数据；刷新页面后临时变更会重置。

## 6. 冻结周验证口径

第13周优先使用统一入口做正式回归：

```powershell
py -3 -m pytest -q
```

如需要按冻结周最小集合拆分定位，可使用：

```powershell
node --check src\ui\static\app.js
py -3 -B tests\test_routing.py
py -3 -B tests\test_integration.py
py -3 -B tests\test_course_requirements.py
py -3 -B tests\test_ui_demo.py
```

浏览器验收前先确认端口：

```powershell
netstat -ano | findstr :8765
```

若个别本机环境无法完成统一入口，仍以本节最小回归集合为冻结证据，并记录失败或超时原因。
