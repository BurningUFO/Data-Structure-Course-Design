# 用户使用说明

> 文档状态：第 13 周前形成可用版，第 14-15 周根据实际演示和试用反馈继续润色。

---

## 1. 系统简介

本系统面向景区 / 校园游览场景，提供旅游推荐、路线规划、场所查询、美食推荐、旅游日记管理与交流等功能。正式验收以 Web UI 为主入口，CLI 仅作为兜底调试方式。

---

## 2. 启动方式

### 2.1 环境要求

- Windows + Python 3
- 项目代码位于仓库根目录

### 2.2 启动步骤

1. 打开项目根目录终端。
2. 运行：

```powershell
py -m src.ui.demo_server
```

3. 在浏览器访问：

```text
http://127.0.0.1:8765
```

---

## 3. 主要页面说明

### 3.1 首页 / 站点选择

- 查看当前可用站点、系统统计信息和预设演示入口。
- 切换站点后，当前查询条件和路径高亮会自动重置。

### 3.2 综合查询与推荐

- 输入景点 / 学校名称、类别或关键字进行查询。
- 可按热度、评分和兴趣权重查看推荐结果。

### 3.3 导航规划

- 输入起点和目标点，可查看最短距离或最短时间路线。
- 多目标模式支持依次访问多个地点并返回起点。

### 3.4 场所与美食

- 查询附近设施，支持按类别过滤。
- 查看按热度、评分和真实路径距离排序的美食推荐结果。

### 3.5 日记中心

- 支持日记创建、编辑、删除、评分和浏览量展示。
- 支持按目的地、标题和正文关键字检索日记。
- 可查看压缩 / 解压摘要与 AIGC 动画预览入口。

### 3.6 帮助与演示

- 使用固定预设参数快速跑通验收链路。
- 查看错误提示说明、输入约束和演示建议步骤。

---

## 4. 推荐操作流程

### 4.1 景点推荐

1. 进入“综合查询与推荐”。
2. 选择站点或输入关键字。
3. 选择排序方式或兴趣权重。
4. 查看 Top-K 推荐结果。

### 4.2 路线规划

1. 进入“导航规划”。
2. 选择起点、目标点和路线策略。
3. 点击查询，查看路径高亮、步骤说明和距离 / 时间摘要。

### 4.3 日记检索与 AIGC 预览

1. 进入“日记中心”。
2. 输入标题、目的地或正文关键字。
3. 查看命中日记、匹配词和评分信息。
4. 如需演示 AIGC，上传或选择样例图片并输入文字描述，查看预览结果。

---

## 5. 注意事项

- 如果切换站点后结果异常，请重新执行查询，避免沿用旧状态。
- 路线不可达时，系统会给出失败提示，不会强行返回伪路径。
- AIGC 动画生成功能当前为轻量演示版本，重点展示输入输出闭环，不代表最终商用级生成质量。
