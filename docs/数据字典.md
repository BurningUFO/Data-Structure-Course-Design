# 数据字典与分层结构说明 (面向成员 C)

> 成员 C 请注意：本项目已切换为**纯分层图结构**。请严格按照以下标准准备数据。

## 1. 目录结构规范
数据需按层级解耦，不要全部塞进一个文件。
```text
data/
├── global_sites.json      # 全局景区列表（包含景区 ID、名称）
└── sites/
    └── PKU/               # 某个景区的文件夹（ID 为 PKU）
        ├── outdoor.json   # 景区的室外道路图
        ├── indoor_LIB.json # 图书馆室内图
        └── indoor_DORM1.json # 宿舍 1 室内图
```

## 2. JSON 字段要求

### 2.1 节点 (Nodes)
在 `outdoor.json` 或 `indoor_XXX.json` 中定义。
- `id`: 全局唯一 ID。
- `is_gate`: (bool) **非常重要**。如果这个点是建筑的入口，或者景区的入口，必须标为 `true`。
- `sub_graph_id`: (string/null) 如果该点是门，指向它连接的室内图 ID（如 `indoor_LIB`）。

### 2.2 边 (Edges)
- `from`, `to`: 节点 ID。
- `distance`: 物理长度（米）。
- `type`: `outdoor_road` (室外道路), `indoor_path` (室内走廊), `elevator` (电梯), `stairs` (楼梯)。
