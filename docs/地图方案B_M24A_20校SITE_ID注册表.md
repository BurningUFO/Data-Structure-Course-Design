# 地图方案 B M24A 20 校 SITE_ID 注册表

## 范围边界

本文件是 M24A 的冻结产物，供 M24B 及后续阶段统一引用。M24A 只固定扩展名单、`SITE_ID`、中文名、城市和优先级，不创建 `data/sites/<SITE_ID>/` 目录，不写入 `data/global_sites.json`，不补任何具体校园图数据。

当前 `PKU` 是既有基线站点，不计入本轮 20 所扩展校园名单；后续阶段不得把 `PKU` 改名、迁移或重建为新站点。

## SITE_ID 规则

1. `SITE_ID` 使用大写 ASCII 字母，保持全局唯一。
2. 优先使用高校通用英文缩写；存在歧义时使用更明确的稳定缩写，例如 `TONGJI`、`HZAU`。
3. `PKU` 为既有基线保留 ID，本表 20 个扩展 ID 不得与其冲突。
4. 后续阶段一旦写入目录或 `global_sites.json`，不得随意改名；确需改名时必须同步迁移目录、注册表、测试与文档引用。
