# 课程要求覆盖清单

> 用途：把课程原始要求映射到当前项目交付，作为第 13 周内部验收和第 15 周正式验收的统一核对表。  
> 当前内部交付目标：**第 13 周（2026-05-25 至 2026-05-31）形成正式产品，第 14-15 周只做体验优化与验收收口。**

---

## 1. 功能覆盖

| 课程要求 | 当前落点 | 负责人 | 第13周门槛 |
|----------|----------|--------|------------|
| 旅游推荐 | `src/search/`、`src/recommend/`、Web 首页/综合查询页 | 成员 B | 景点/学校推荐、排序、Top-K、模糊查询均可演示 |
| 旅游路线规划 | `src/graph/`、`src/routing/`、导航规划页 | 成员 A | 单目标、多目标、最短距离、最短时间、交通方式、室内导航均可演示 |
| 场所查询 | `src/search/`、场所与美食页 | 成员 B + A | 支持类别过滤，按真实路径距离排序 |
| 旅游日记管理 | `src/diary/`、日记中心 | 成员 B + C | 支持创建、编辑、删除、评分、浏览量展示和媒体占位 |
| 旅游日记交流 | `src/diary/`、`src/compress/`、日记中心 | 成员 B + C | 目的地查询、标题精确查找、全文检索、压缩 / 解压均可演示 |
| AIGC 动画生成 | `src/ui/` + 日记中心 / 演示模式 | 成员 B + C | 提供真实可见的轻量输出，允许模板化动画、分镜页或 GIF |
| 美食推荐 | `src/recommend/`、场所与美食页 | 成员 B + A | 支持热度、评分、距离排序和菜系过滤 |

## 2. 数据规模硬指标

| 指标 | 课程要求 | 当前计划口径 | 负责人 | 截止时间 |
|------|----------|--------------|--------|----------|
| 景区与校园数量 | `>=200` | 1 个深度导航核心站点 + 200+ 推荐 / 查询对象 | 成员 C | 第12周 |
| 每处建筑物数量 | `>=20` | 核心站点达到 20+ 建筑物 / 景点 / 楼宇节点 | 成员 C + A | 第12周 |
| 服务设施种类 | `>=10` | 核心站点覆盖 10+ 设施类别 | 成员 C | 第12周 |
| 服务设施总数 | `>=50` | 核心站点与扩展数据合计 50+ 设施 | 成员 C | 第12周 |
| 道路图边数 | `>=200` | 核心导航图达到 200+ 边 | 成员 C + A | 第12周 |
| 系统用户数 | `>=10` | 维护 10+ 用户样例数据 | 成员 C | 第11周 |

> 说明：数据核验记录应在第 12 周前形成书面说明，供第 13 周内部验收和第 15 周正式验收引用。

## 4. 第13周内部验收门槛

1. Web UI 可直接启动，且六大功能都能从浏览器内完成演示。
2. 数据规模硬指标已有核验记录，不再仅停留在“后续补齐”。
3. 日记管理具备 CRUD、评分、多媒体占位和全文检索联动。
4. AIGC 动画生成功能有真实输出，不是纯文档说明。
5. 用户说明、评价与改进、AI 能力分析等课程要求文档均已有初稿。

---

## 5. 第14-15周边界

- 可以做：体验优化、性能调优、文案润色、答疑反馈修正、报告/PPT/打包、彩排。
- 不可以做：新增课程硬功能、推翻接口、重新设计页面结构、拖延数据规模达标。
