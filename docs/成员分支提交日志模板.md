## 示例

### 记录编号：`20260401-01`

- 日期：2026-04-01
- 分支名：`feature/path-planning`
- 提交人：张三
- 对应 commit：`abc1234`
- 本次任务：完成单目标最短路径模块的初版
- 关联需求：旅游路线规划 / 最短距离策略
- 是否涉及核心算法：是
- 涉及算法：Dijkstra、邻接表
- 是否完成自测：是

#### 1. 本次完成内容

- 完成景区道路图的数据读取
- 完成单目标最短路径计算接口
- 输出路径节点序列和总距离

#### 2. 修改文件

- `src/graph/graph.h`
- `src/graph/graph.cpp`
- `tests/test_shortest_path.cpp`

#### 3. 关键改动说明

- 改了什么：新增图结构和最短路径计算逻辑
- 为什么这样改：为后续多目标路径和场所查询复用图能力
- 是否影响他人模块：会影响地图展示模块的接口联调

#### 4. 算法与数据结构说明

- 使用的数据结构：邻接表、最小堆
- 使用的算法：Dijkstra
- 时间复杂度：`O((V + E) log V)`
- 空间复杂度：`O(V + E)`
- 与备选方案的对比：相比 Floyd 更适合单源查询和动态扩展

#### 5. 测试记录

- 测试方式：手工构造图 + 单元测试
- 测试数据：10 个节点、14 条边
- 测试结果：最短路径长度与预期一致
- 已知问题：暂未加入拥挤度和交通工具约束

#### 6. 待合并说明

- 合并到目标分支：`main`
- 合并前依赖：等待地图节点命名规范确定
- 需要谁协助评审：李四
- 是否可以直接合并：否

#### 7. 下一步计划

- 增加最短时间策略
- 预留多目标路径接口
