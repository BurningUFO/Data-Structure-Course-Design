# 项目创新点

本文档汇总本课程设计在**智能推荐与检索**、**微观场景导航**及**弱网离线体系**等方面的创新设想与分工衔接说明。

---

## 一、AI 推荐与检索（成员协作与亮点）

### 1. 多目标自定义排序

允许用户自行调节各维度权重，例如：

> 热度 40% + 评分 30% + 距离 30%

- **分工建议**：成员 B 负责排序模型（加权融合、归一化与可解释展示）；成员 A 提供真实距离等空间相关特征，保证排序与地理事实一致。

### 2. 动态兴趣画像与可解释个性化推荐

在传统“用户预设兴趣标签”的基础上，系统进一步引入**动态兴趣画像**机制，使推荐结果能够随用户使用过程逐步自适应变化。

- 前端按 `site_id + user_id` 维护本地兴趣权重画像，根据用户查看推荐卡片、打开结果详情、地图定位、规划路线、查附近设施等行为实时更新兴趣权重。
- 系统自动从画像中提取 Top-N 兴趣标签，继续回填到原有 `interests` 兼容路径，因此旧搜索、推荐和用户切换逻辑不需要重写。
- 后端可选接收 `interest_profile`，在保留静态硬标签的同时，将不同标签权重纳入 `category / tags / keywords` 命中得分，让“更强兴趣”真正影响推荐排序。
- 画像更新加入时间衰减、动作分级、权重封顶与归一化，避免一次偶发点击长期污染偏好；推荐结果中保留兴趣命中原因和权重贡献说明，便于答辩时解释“为什么推荐发生变化”。

该创新点把“用户行为感知、兴趣权重建模、兼容式推荐排序、可解释输出”串成闭环，使系统从固定偏好推荐升级为可持续学习的个性化导览推荐。

### 3. 模糊查询增强

在普通关键词匹配之上，增强检索体验与命中率：

- 支持**错别字容错**、**拼音首字母**、**同义词**与**关键字联想**。
- 示例：输入「烧烤」「烤串」「bbq」等均可关联到相近美食类目或 POI。

该能力比普通精确查找更具产品亮点，也更贴合真实用户输入习惯。

### 4. 动态 Top-K 推荐

避免每次对全量候选做完整排序：

- 采用**堆（优先队列）**或**快速选择**等结构，仅维护前 **K** 条（如 Top 10）。
- 在候选规模较大时，可降低平均计算量，便于与实时刷新、滑动加载等交互结合。

## 二、创新点一：面向微观场景的时空动态多目标导航引擎

### 核心痛点

现有商业地图导航主要面向**宏观城市道路**的「单点至单点」规划，难以覆盖**大型封闭园区**（校园、景区等）内的微观寻路需求，尤其缺乏：

- **室内外跨层**一体化表达与导航；
- **多交通工具无缝切换**（步行 / 骑车 / 电梯等）；
- 在考虑**节点拥挤度随时间变化**的前提下，对**多目标点（TSP 类）**路径进行更优规划。

### 技术创新与实现思路

1. **多模态复杂图构建**  
   建立室内外**多层级拓扑网络**，将电梯、单车道、步行道等统一纳入同一图结构，支持多模态交通工具的混合调度与约束表达。

2. **4D 时空动态权值**  
   引入**时间维度（Time-varying）**，将实时或预测的拥挤度（如午间食堂高峰）映射为**动态边权**，使路径代价随时段变化。

3. **核心算法支撑**  
   面向「多目标点游览」类需求，在动态权值图上结合**状态压缩动态规划**与**改进的 Dijkstra**（或与之配套的分层、剪枝策略），在约束条件下求解较短/较优时间路径，实现**智能避峰**与**路线动态自适应**规划。

## 三、创新点二：弱网环境下的高密度离线检索与存储框架

### 核心痛点

传统旅游类应用强依赖实时网络，在偏远景区、建筑深处（地下室、展馆等）易出现**信息断层**。常见做法包括全量本地缓存，但会带来：

- **存储开销**过大；
- 离线状态下往往**难以支持高效文本检索**。

### 技术创新与实现思路

1. **高优离线同步机制**  
   预先拉取并打包**高价值长尾数据**（如 Top 50 优质游记、紧急联络点、避坑指南等），在无网环境下仍能提供基础信息保障。

2. **极值无损压缩存储**  
   底层基于**哈夫曼树（Huffman Tree）**编码：对海量中文游记等文本进行**字符级频率统计**与**无损压缩**，降低传输带宽与终端存储占用。

3. **纯本地倒排全文检索**  
   在压缩后的本地数据体系上构建**倒排索引（Inverted Index）**，使用户在**完全断网**时仍能对「急救」「洗手间」等关键词进行**高效、相对精准**的全文检索。

| 方向 | 要点 |
|------|------|
| 推荐与检索 | 可配置多目标排序、动态兴趣画像、权重化可解释推荐、模糊与联想查询、Top-K 动态维护 |
| 微观导航 | 多模态图层、时空动态权值、状态压缩 DP + 改进最短路 |
