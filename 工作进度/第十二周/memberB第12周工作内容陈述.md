## 3. Web 主入口接入情况

当前 Web 主入口仍以以下命令启动：

```powershell
python -B -m src.ui.demo_server
```

浏览器访问：

```text
http://127.0.0.1:8765
```

当前可从 Web 主入口直接进入的成员 B 相关功能包括：

1. **综合查询**：支持输入地点关键字，返回地点结果，并可从结果继续进入路线规划。
2. **场所查询**：支持洗手间、便利店、教学楼等场所检索，并结合当前起点展示距离排序结果。
3. **美食推荐**：支持餐饮相关 Top-K 推荐和距离 / 评分 / 热度等排序展示。
4. **导航规划**：支持单目标路径、多目标路径、路线摘要和路径步骤展示。
5. **日记中心**：支持推荐浏览、全文检索、日记管理入口和目的地路线联动。
6. **AIGC 演示**：支持轻量模板化预览结果展示，作为第 13 周正式产品中的可见演示能力。
7. **帮助说明**：保留演示链路和当前阶段说明入口，便于后续答辩统一口径。

## 4. 关键演示流收口

### 4.1 查询 / 推荐到路径规划

本周继续保持综合查询、场所查询和美食推荐结果与路线规划联动：

1. 用户先在 Web 页面输入关键词；
2. 页面返回统一结果卡片；
3. 用户可从结果卡片进入地图定位或路线规划；
4. 路线摘要、路径步骤和地图高亮同步更新。

该链路保证成员 B 的查询、排序、推荐结果不是孤立展示，而是可以继续接入 Member A 的路径能力。

### 4.2 单目标 / 多目标路径展示

本周继续保持多目标路径的页面展示口径：

1. 单目标路径展示总距离、预计时间和步骤说明；
2. 多目标路径展示访问顺序、总距离、总时间、分段摘要和关键路径步骤；
3. Web 页面继续依赖 `visit_order`、`visit_order_names`、`leg_results`、`segments`、`path_steps` 等稳定字段；
4. 后续如路径接口扩展字段，只允许追加，不应改名或改变现有语义。

### 4.3 日记中心到路线规划

日记中心当前保留以下演示能力：

1. 浏览推荐日记；
2. 按全文关键词检索日记；
3. 查看日记关联目的地；
4. 从日记结果进入路线规划；
5. 保留创建、编辑、评分、删除和媒体占位相关入口。

需要说明的是，当前日记管理仍采用 `memory_only` 轻量演示口径，不直接写回正式数据文件。

### 4.4 AIGC 轻量预览

AIGC 当前定位为轻量可见演示能力：

1. 页面提供 AIGC 演示入口；
2. 用户可选择样例或输入描述；
3. 系统返回模板化分镜预览；
4. 当前不调用真实生成模型，不承诺真实图片或视频生成。

该口径需要在第 13 周答辩和帮助说明中保持一致，避免被误解为真实生成模型已完整接入。
