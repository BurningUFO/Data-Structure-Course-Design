## 4. 统一验收口径

1. 浏览器直接访问 `http://127.0.0.1:8765`，不要求先跑 CLI 交互。
2. 任一核心功能都必须能从 Web 主入口进入、触发、看到结果，并有可读反馈。
3. 多目标路径不只返回总距离，还必须能展示访问顺序、关键分段和总时间摘要。
4. 日记中心不只停留在查询，必须保留创建、编辑、评分、删除、媒体占位和目的地跳转能力。
5. AIGC 轻量演示允许模板化输出，但必须在页面上给出真实可见结果，而不是仅显示“待实现”。
