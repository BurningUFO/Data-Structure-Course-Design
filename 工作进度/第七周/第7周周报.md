## 2. 成员详细工作汇报

### 【Member A：图结构与路径规划】
**本周主要成果：**
1. **Dijkstra 核心算法落地**：在 `src/routing/router.py` 中实现了单源最短路径搜索，并使用 `heapq` 进行优先级队列优化，保证了算法在大规模图场景下的高效性。
2. **多策略动态权重支持**：实现了 `最短距离` 和 `最短时间` 两种策略切换。引入了理想速度和拥挤系数换算，支持拥挤路段的避堵绕行。
3. **交付核心接口**：
    - 提供 `query_routing`：返回完整路径和权重，兼容分层图设计。
    - 提供 `query_distance`：专供 Member B 调用，用于推荐系统的距离排序。
4. **单元测试通过**：在 `tests/test_routing.py` 中构建综合测试图验证了上述逻辑，孤立点拦截和绕行逻辑均测试通过。

### 【Member B：查询、排序与推荐业务】
**本周主要成果：**
1. **基础查询逻辑实现**：在 `src/search/` 下实现了精确查询、按类别过滤、以及轻量级模糊匹配逻辑。
2. **业务闭环打通**：编写 `cli_demo.py`，将第六周的 Top-K 和排序模块整合，跑通了“输入关键字 -> 查询过滤 -> Top-K 排序 -> 返回结果”的演示链路。
3. **统一响应规范**：在 `response.py` 中定义了通用响应结构（包含 success, data, message 等字段），为前后端联调提供标准。
4. **单元测试通过**：编写并运行了 `tests/test_search.py`，完整覆盖了多种查询场景及主链路功能。

### 【Member C：数据测试与系统集成】
**本周主要成果：**
1. **测试数据扩充**：扩充了系统的基础测试数据（约 1100 行），为后续联调准备了丰富的测试用例，主要包含：
    - `NodeWithEdges.json`：包含节点与连通边的数据。

    - `diary_test.json`：旅游日记及评价数据。
