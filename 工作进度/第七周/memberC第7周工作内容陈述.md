## 二、数据库索引学习成果

### 2.1 核心知识点梳理

| 索引类型 | 适用场景 | 本项目应用 |
|----------|----------|------------|
| **B+树索引** | 范围查询、排序 | 景点名称模糊搜索、时间排序 |
| **哈希索引** | 等值查询 | 景点ID精确查找 |
| **联合索引** | 多条件查询 | 景点类型+区域组合查询 |
| **全文索引** | 文本匹配 | 景点描述关键字搜索 |

### 2.2 索引优化实践

**已应用的优化策略：**
- ✅ 为查询高频字段建立单列索引
- ✅ 遵循最左前缀原则设计联合索引
- ✅ 避免在索引列上进行函数操作
- ✅ 合理控制索引数量，减少写入开销

**项目具体方案：**
```sql
-- 景点表索引设计
CREATE INDEX idx_scenic_type_area ON scenic(type, area);      -- 联合索引
CREATE INDEX idx_scenic_name ON scenic(name);                 -- 名称搜索
CREATE INDEX idx_scenic_rating ON scenic(rating DESC);        -- 评分排序

-- 路线表索引设计
CREATE INDEX idx_route_distance ON route(distance);           -- 距离排序
CREATE INDEX idx_route_time ON route(estimated_time);         -- 时间排序
```
