## 3. 本周协作原则与禁止事项

### 3.1 协作原则

1. **冻结优先于扩展**：本周只允许修正式产品阻塞问题，不再新增课程硬功能。
2. **追加优先于改语义**：若确需补字段，只允许追加，不允许修改已有字段含义、重命名接口字段或改动现有输入输出协议。
3. **证据优先于口头说明**：所有“已完成”项都必须有页面、脚本、文档或测试结果支撑。
4. **浏览器主入口优先**：正式验收以 `http://127.0.0.1:8765` Web 主入口为准，CLI 仅作兜底调试。

### 3.2 本周禁止事项

1. 不允许继续扩大功能面，例如新增新的课程硬功能、重做路由算法、重写推荐策略或引入真实模型服务。
2. 不允许承诺“全部 208 个扩展对象都能直接深度导航”，本周只保护好现有核心样例。
3. 不允许对页面结构做大改版，避免冻结周末再同步一轮大规模 UI 断言。
4. 不允许在未同步文档和测试的情况下修改接口、数据口径或演示流程。
